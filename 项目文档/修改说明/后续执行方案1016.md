## 三、三个可选方案

### 方案 A：保守调整，先把现有模型训练好

**适合：希望改动少、训练时间可控，先确认恢复 AUROC 后的效果。**

模型结构完全不动：

- 五层卷积、现有通道数量保持不变。
- 输入仍为64×64。
- 保留 LeakyReLU、现有 Dropout、Adam 和均衡采样。

建议下一次小规模续训参数：

| 参数       | 建议                      |
| ---------- | ------------------------- |
| 起点       | 昨日 AUROC 最佳权重       |
| 学习率     | 从当前 `5e-5` 降到 `1e-5` |
| 每批图片   | 保持64                    |
| 最多训练   | 8轮                       |
| 学习率下降 | AUROC 连续2轮无改善时减半 |
| 提前停止   | AUROC 连续4轮无改善       |
| 最低学习率 | 保持 `1e-6`               |

这些是**下一轮实验的起始设置，不是已经验证的最优参数**。先恢复评价规则建立基线，再测试小学习率，避免混淆两个因素。

优点是能继续利用现有模型；不足是可能接近现有结构的能力上限。

### 方案 B：保留五层 CNN，缩小分类部分，再尝试提高分辨率——推荐方向

**适合：既想提升质量，又不希望模型越来越复杂。**

目前模型约1521万参数，其中约90%集中在最后的全连接部分。我的判断是：**现在不缺参数，更值得检查的是参数是否用在了有效位置。**

分两步做，不能一起改完后只看一个结果。

**B1：先只缩减全连接层**

目前：

```
4608 → 2048 → 2048 → 2
```

建议先试：

```
4608 → 512 → 2
```

其余卷积、池化、输入尺寸和激活函数保持不变，Dropout 第一轮对照也先保持0.5。

- 按结构计算，总参数约降到393万，FP32权重约16MB。
- 目标是减少不必要的记忆能力和参数更新开销。
- **不保证训练时间按参数比例下降**，因为主要卷积计算仍然保留。
- 已有卷积权重可以迁移，新的全连接层需要重新训练，不能直接加载整个旧分类头。

训练时可让已有卷积使用较小学习率，如 `1e-5`；新分类层使用 `1e-4`。先设最多15轮，连续5轮验证 AUROC 不提高就停止。

**B2：B1有效后，再单独试96×96输入**

当前把整张眼底照片缩到64×64，存在丢失细节的可能，但这仍需要实验验证。

- 先试96×96，不直接跳到224或更大。
- 保留当前3×3自适应平均池化，固定进入分类层的尺寸。[PyTorch说明](https://docs.pytorch.org/docs/2.10/generated/torch.nn.AdaptiveAvgPool2d.html)
- 不再额外增加池化次数，以免进一步压缩空间信息。
- 必须重新测试单张延迟。**之前64×64的测速结果不能直接用于96×96。**

这一路线的核心是：**减少庞大的分类层，把算力优先用于看清图像，而不是一味扩大网络。**

### 方案 C：模型先不动，优先改善训练样本的使用方式

**适合：希望保留课堂 CNN 结构，主要通过数据处理提升泛化。**

目前训练集有1657张阳性，均衡采样使阳性约占每轮抽样的一半。按期望计算，每张阳性每轮会被抽到约15.5次，而现有随机增强只有水平翻转。

这可能让模型反复记住少数阳性图片，但不能仅凭次数就断定它是根因。

建议分别验证：

1. **温和增强**：保留水平翻转，尝试小角度旋转、轻微亮度和对比度变化；避免大幅裁剪、强烈颜色变化。
2. **降低阳性重复比例**：对照当前50%阳性采样，试25%阳性采样。
3. 采样对照时保持普通交叉熵，暂不同时增加类别加权或 Focal Loss，避免多个因素混在一起。

风险是增强过强或阳性采样不足也会降低效果，因此两项要分开实验。

## 四、我建议你怎么选？

**推荐顺序：A → B1 → 视结果选择 B2 或 C。**

暂时不优先做以下事情：

- 继续加深卷积、把通道扩大到1024；
- 再增加池化层；
- 同时更换激活函数、损失函数和优化器；
- 为追求更高训练准确率而延长训练。

当前 LeakyReLU 已经可以工作，缺少证据证明它是主要瓶颈；Dropout 也不是越大越好。

每次只比较一个主要变化，使用相同验证集和起始条件。对最有希望的方案再补一次不同随机种子的复验，避免把一次偶然上涨当成稳定提升；官网测试集不作为反复调参的验证集。

**你可以选择：A“小改稳住”、B“先A再精简模型，推荐”、C“先A再优化增强与采样”。** 无论选择哪项，都保留旧模型；代码检查完成后由你训练，不承诺未经实验的提分幅度。
