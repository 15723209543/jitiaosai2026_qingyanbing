# 执行计划

我的建议是把 `submission4` 设计为下面五个独立训练的分支，最后装进**一份 `.pth` 文件**：

| 分支 | 模型                                | 选择理由                                                     |
| ---- | ----------------------------------- | ------------------------------------------------------------ |
| 1    | 你原来的五层 CNN（v1.5.1 可用版本） | 保留你的课堂代码路线；不能误用现在的 ResNet 文件冒充它       |
| 2    | ResNet18                            | 当前三模型中验证 AUROC 最高，约 0.9295                       |
| 3    | DenseNet121                         | 当前验证 AUROC 约 0.9247，提供不同的特征结构                 |
| 4    | EfficientNet-B0                     | 按你的要求保留，但目前仅约 0.8644，必须检验它是否拖累投票    |
| 5    | ConvNeXt-Tiny                       | 作为新架构候选；出自 [CVPR 2022 论文](https://openaccess.thecvf.com/content/CVPR2022/html/Liu_A_ConvNet_for_the_2020s_CVPR_2022_paper.html)，可用 [torchvision 实现](https://docs.pytorch.org/vision/main/models/convnext.html)，但在本数据上有效与否需要实测 |

训练时，先用验证集测五个分支的起点；此后每轮依次训练、验证五个模型，各自仅在**自身验证 AUROC 提高**时更新“单模型最佳”。一轮结束，再用五个模型共同验证；仅在**五模型组合 AUROC 提高**时保存“组合最佳”。这两套“最佳”不能混为一谈，但可以作为不同字段封装在同一个 `.pth` 中；实现前会核算文件大小，确保低于 500 MB。训练启动时只打印一次实际使用的 CPU/GPU 信息。

预测时，五个模型各输出阳性概率 \(p_1,\ldots,p_5\)。建议提交 `Probability = median(p1,…,p5)`，`Pred_Label = 1[Probability ≥ 0.5]`：后者正好是你要的“三票及以上为阳性”，前者仍保留连续分数供 AUROC 评分使用。**不要把 Probability 直接写成 0/1 投票结果**。[赛题页面](https://www.ncccu.org.cn/index/Paper/case2.html?way=1)以 AUROC 为主要指标，并有限制模型大小和单张推理时间；五模型串行推理是否满足 100 ms，必须实际测速，不能预先保证。

需要提前说明一个风险：最新仓库里的三模型组合 AUROC 约 **0.9295**，几乎没有超过单独的 ResNet18；历史 ResNet18＋DenseNet121 组合曾达到约 **0.9431**。所以增加到五票并不必然提分，较弱分支可能压低召回率。眼底研究也提示关注病灶相关区域，而不只是堆模型；可参考 [CVPR 2019 的青光眼注意力研究](https://openaccess.thecvf.com/content_CVPR_2019/html/Li_Attention_Based_Glaucoma_Detection_A_Large-Scale_Database_and_CNN_Model_CVPR_2019_paper.html)，但不使用其外部数据或预训练权重。我检索到了相关公开研究代码，例如 [AG-CNN](https://github.com/smilell/AG-CNN)，**未找到可核实属于本届同一赛题的公开参赛仓库**。

我的方案如下，现在我们把模型给升级为五个模型。这五个模型分别是我最初写的CNN最后一版可用的那一个，然后就是最新的三个模型，然后你再自己选一个模型，然后进行五选三。五个模型单独进行训练，但是最终生成的一个PTH文件。五个模型对同一事件进行分别预测，只要有其中三个报了它是有问题的，就把它标记为有问题，否则认定为无问题。

特别说明一下，要求和原来一样，新写一个submission4文件夹。你只需要把代码写好就行了，保证可以进行使用。特别注意，训练之前需要建议使用GPU进行训练，信息需要打印； 第一轮开始训练的时候，需要在训练之前用验证集进行验证，保证训练的第一轮的参数更正有依据；后面每一轮训练都依次使用五个模型单独进行训练，验证集每个模型验证一次，每个模型验证之后， 基于和这个模型的上一次的最佳数据相比，决定是否更正。五个模型训练完之后，同时使用五个模型对整个验证集的数据进行一次确认，打印 AUROC值。如果是这个 AUROC值相较于上一次最好的五个模型一起验证的 AUROC值有变化，把这一轮所有模型参数更正。也就是说，目前更正参数有两种可能，一种可能就是单独训练的时候发现比上一轮好，或者就是整体训练的时候发现比原来好。
