# 后续调整与规划（方案A，v1.5.2）

日期：2026-10-17。本版代码改为ResNet-18随机初始化与128像素输入，正式训练由用户运行。92分旧冠军、配置和CSV在代码修改时不覆盖；训练开始也会备份原冠军。

## 第一阶段：完成128像素实验

1. 用jitiaosai运行train.py。观察首批/每25批/末批进度，以及每轮训练loss/acc和独立验证AUROC/AUPRC/召回率。
2. 数据只使用主办方train/valid。ResNet与旧CNN结构不同，不迁移旧卷积参数；新模型从零开始。第一次最少10轮、最多30轮、候选自身验证AUROC连续8轮不改善后早停。
3. 到项目文档/训练记录/时间目录查看训练历史、本轮候选best_model.pth以及训练前baseline_model.pth备份。仅当新验证AUROC严格超过全局冠军时才替换submission/model/best_model.pth。
4. 用户需要提交成绩时单独运行predict.py。该文件读取正式模型自己的输入尺寸，生成results/submission.csv；训练不写答案。

## 第二阶段：受控对照

- 若128像素验证AUROC明显提升，再单独评估160像素：只改输入尺寸并训练新候选，测速和权重配置同时验证。不要直接拿128像素参数冒充160像素模型。
- 如果训练准确率持续升、验证AUROC下降，先对照减弱增强或降低均衡采样中的阳性比例，再考虑网络容量；一次只改一项。
- 若训练和验证均较差，先复核学习率曲线、采样和归一化，再评估MobileNetV3或EfficientNet。模型名称本身不保证提分。
- 有希望的方案再换随机种子复验。官方验证阳性仅191例，细小涨幅可能波动。官网分数与本地验证AUROC分别记录，不用训练集参与选模。

## 速度、大小和比赛规则

ResNet-18约11177538个参数，FP32裸参数约44.71MB；以实际保存的pth尺寸验收≤500MB。单张端到端≤100ms应在最终运行环境测量，至少包含读图、缩放、网络前向。抽样测速只说明本机当时状况，不构成官方达标保证。

只使用主办方数据；不下载外部预训练权重。训练原图留本地。助手只修改源码、做轻量检查和提交；正式训练、整批预测、官网上传由用户运行。
