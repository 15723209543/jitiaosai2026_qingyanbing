## 2. 数据与流程

图片与CSV对应：glaucoma_first/train.csv和train/；valid.csv和valid/；test.csv和test/。
训练51396张、验证5849张、测试5855张。训练和验证表有Image_name、Age、True_Label，测试表只有Image_name、Age。当前模型只用图片；1为阳性，0为阴性。

```text
train.py → 读取train/valid → 按旧配置验证旧模型（epoch=0）
         → 加宽时只继承前三层卷积、其余重新初始化 → 训练一轮 → 验证
         → AUROC优先、相同看AUPRC决定保存 → 按自身AUROC调整学习率 → 保存本次记录
         → 提前停止或达到12轮 → 退出，不生成答案

predict.py → 按pth内配置加载模型 → 读取test清单和图片
           → eval/no_grad预测 → 阳性概率 → 官方三列CSV
```

路径根据源码所在位置确定，与编辑器工作目录无关。valid有真实标签，test无公开标签，不能计算本地真实测试准确率。

## 3. 模型和算法

新训练固定结构（模型内不再提供extra_convs层数开关）：

```text
RGB 3×64×64
→ Conv(3,32,3) → LeakyReLU → MaxPool(2)     32×31×31
→ Conv(32,64,3) → LeakyReLU → MaxPool(2)    64×14×14
→ Conv(64,128,3) → LeakyReLU               128×12×12
→ Conv(128,256,3,padding=1) → LeakyReLU     256×12×12
→ Conv(256,512,3,padding=1) → LeakyReLU     512×12×12
→ MaxPool(2) → Dropout2d(0.1)              512×6×6
→ AdaptiveAvgPool(3×3)                    512×3×3
→ 拉平                                   4608
→ Linear(4608,2048) → LeakyReLU → Dropout(0.5)
→ Linear(2048,2048) → LeakyReLU → Dropout(0.5)
→ Linear(2048,2)                          两类logits
```

卷积是局部加权求和，共享卷积核提取特征；最大池化保留局部强响应，平均池化汇总局部信息，全连接综合判断类别。共15208258个参数，float32权重约60.83MB；文件另含少量序列化元数据，检查小于500MB。三次最大池化后再做一次自适应平均池化，把512×6×6压缩为512×3×3，避免全连接参数剧增。池化会损失空间细节，并非越多越好；加宽也增加计算量，不保证提分。

新层使用PyTorch默认初始化，不再使用Dirac。旧三层或窄五层迁移到宽五层时，只继承conv1/2/3的权重和偏置。虽然拉平长度仍为4608，但旧特征是128×6×6，新特征是512×3×3，语义不同，因此全连接层也重新初始化。同一宽五层模型再次运行时恢复全部权重。不冻结层，不新增预训练数据或外部模型。

LeakyReLU在x≥0时输出x，x<0时输出0.01x，负半轴保留小梯度；是否优于ReLU需验证。旧纯权重加载时仍用ReLU，带配置的v1.2.x权重沿用文件中的激活设置。
Dropout2d按0.1概率临时关闭整张特征通道；全连接Dropout按0.5概率关闭部分激活，不删除神经元。eval时关闭随机失活。

交叉熵可简化为loss=-ln(真实类别概率)。Adam沿梯度更新权重，weight_decay=1e-4加入L2正则项抑制权重过大；打印的loss只包含交叉熵，不含该正则项。训练loss下降不代表验证一定改善。

阴性49739张、阳性1657张。每张图采样权重为所属类别数量的倒数，两类总权重相等，抽样概率各约一半。有放回抽取51396次，不保证每图出现一次。均衡采样后不再额外加权交叉熵。

图片缩小至64×64、转Tensor、按均值/标准差0.5标准化。训练随机水平翻转，验证/测试确定性处理。内存缓存缩略RGB图，避免重复解码，不改写原图。

## 4. model.py全部函数

### create_dataset()

来源：课堂CNN todo1。调用utils.load_train_data，返回训练和验证Dataset。

### ImageModel.__init__(negative_slope=0.01, conv_dropout=0.1, dropout=0.5)

来源：课堂CNN网络定义；通道加宽和平均池化为本项目自写修改。创建固定五个卷积层、三个最大池化层、一个平均池化层、全连接与输出，并保存model_config，其中architecture="wide5"标记宽五层结构。
negative_slope=0选择ReLU，否则选择LeakyReLU。model_config描述网络行为，state_dict保存权重。

### ImageModel.forward(x)

来源：课堂CNN前向传播，固定执行五次卷积和激活，第三次最大池化后补充平均池化，不再判断层数。输入[N,3,64,64]，输出[N,2]。
依次卷积、激活、池化、卷积失活、拉平、全连接和输出。输出层不做Softmax，CrossEntropyLoss直接接收logits；预测时再转换为概率。

main只用torchsummary打印默认精调模型结构，不训练或保存文件。

## 5. train.py函数与入口

### train(train_dataset, valid_dataset)

来源：课堂CNN todo3。保留DataLoader、前向传播、交叉熵、zero_grad、backward、step和课堂打印字段。

1. 固定Torch随机种子，设置线程，建立均衡采样DataLoader。
2. 创建新配置模型和按时间命名的独立记录目录。
3. RESUME=True且有权重时，按原模型配置验证并记录epoch=0。
4. 调用utils.transfer_model_weights；旧结构迁移只继承前三层卷积，相同宽结构则恢复全部权重。
5. Adam初始学习率5e-5，L2衰减1e-4；每轮训练后调用predict.evaluate。
6. 完整验证集AUROC优先；AUROC完全相同时，AUPRC更高才保存，两项都相同保留旧模型。准确率和AP不参与保存判断；先写临时文件再替换best_model.pth。
7. 新pth保存format_version=3、state_dict、model_config、image_size和selection_metric="validation_auroc"及tie_break_metric="validation_auprc"，防止配置错配。
8. 学习率和早停观察本次候选模型自身的验证AUROC，不以旧冠军为进步门槛。首轮建立自身基准；随后连续2轮未超过自身最高值则学习率减半，连续10轮未提高则早停；最低学习率1e-6，改善阈值为0。
9. 每轮保存历史与配置，最多12轮；首轮建立候选基准，连续10轮自身AUROC未提高才早停，因此持续停滞时最早第11轮结束。

保存按未经终端四舍五入的(AUROC,AUPRC)比较；调度和早停仅看自身AUROC，AUPRC只用于选模平局决胜。规程第4—5页规定此排名优先级，本地AUPRC沿用梯形积分，官方未公布具体积分算法。官方主要评价指标仍为AUROC；高Acc不保证比赛分数提高，当前验证集全部猜阴性即可得到约96.73%准确率。
RESUME只恢复权重，Adam和调度器状态重新初始化，不是完整断点恢复。未改善时原pth和model/config.json不变。

现有20261015_122314_090403记录中，第3轮Acc约92.51%、AUROC约0.898348；第8轮Acc约94.72%、AUROC约0.892875。旧版按AUROC保留第3轮，不是没有更新训练参数。第8轮只有指标、没有保存权重，不能从CSV恢复。新版以磁盘现有模型重新验证的AUROC/AUPRC为保存基准，不作为候选自身的早停门槛。

用户随后完成了20261015_170909_999522这次训练，共12轮，保存第3轮宽五层模型：AUROC=0.917022、AUPRC=0.419329、Acc=87.23%。当前EARLY_STOPPING_PATIENCE由用户改为10，本版保留。助手没有再训练或重写模型/CSV；历史未保存的第4轮仍不能恢复。

main只读取训练/验证数据并调用train，不读取test、不更新submission.csv。

## 6. predict.py全部函数

### evaluate(test_dataset, model=None)

来源：课堂CNN todo4。test_dataset在这里是有标签验证数据，不是比赛无标签test目录。
传入model时直接验证，未传入时调用load_model。eval/no_grad关闭随机失活和梯度，收集真实标签与Softmax索引1概率，打印并返回完整指标，不写答案CSV。

### predict(test_dir=TEST_DIR, output_csv=OUTPUT_CSV)

来源：课堂测试循环，按2026规程改写。按test.csv顺序加载图片，按pth保存配置加载模型，eval/no_grad推理，提取类别1概率并调用write_submission，返回CSV路径。

## 7. utils.py全部函数

### ImageDataset.__init__(image_paths, labels=None, training=False)

自写数据适配。保存路径、可选标签、图像变换与缓存。训练启用随机翻转，验证/测试不启用。

### ImageDataset.__len__()

复用PyTorch Dataset标准接口，返回图片数量。

### ImageDataset.__getitem__(index)

自写读取接口。首次读取执行JPEG draft、RGB转换、双线性缩放并缓存，重复读取复用缓存；每次训练取样仍重新随机翻转。有标签返回(x,y)，无标签只返回x。

### _load_labeled_images(csv_path, image_dir)

自写标签接口。检查列名、标签0/1、图片存在性，忽略文件名大小写匹配.jpg/.JPG，返回路径和标签。

### load_train_data()

参考课堂create_dataset改写。优先使用官方train/valid；只有缺少valid.csv才以固定随机状态按类别做8:2分层划分。

### create_sampler(labels)

自写类别不平衡处理。缺少任一类时报错，以类别数量倒数为每图权重，返回有放回采样器，每轮抽取原训练样本数。

### print_progress(stage, batch_idx, batch_count, start, detail="")

自写共用打印。首批、每25批及末批显示进度、当前阶段已用秒数、预计剩余分钟数；训练附累计loss/acc。remaining不是整个任务的剩余时间。

### calculate_metrics(labels, positive_probability)

自写指标计算。检查标签包含两类且概率有限，计算AUROC、梯形AUPRC、AP和0.5阈值下的accuracy、recall、specificity、tp/tn/fp/fn。三个排序指标使用连续概率，不使用离散标签。

### load_model(model_path=MODEL_PATH)

自写兼容加载。weights_only=True读取pth，局部导入ImageModel避免循环导入。
新版architecture="wide5"按固定宽五层恢复并检查image_size。兼容逻辑只放工具：旧三层将conv4/5及对应激活、pool4替换为Identity；旧窄五层重建128→128卷积并将pool4替换为Identity。旧纯权重仍按ReLU、无卷积失活加载。严格load_state_dict，不忽略缺失或尺寸不匹配，旧模型预测保持原有结构与数值。

### transfer_model_weights(model, previous_model)

沿用上版工具函数，负责训练开始前的权重迁移。旧结构迁移到宽五层时，只复制conv1/2/3权重和偏置，其余保留新模型初始化值；wide5到wide5恢复全部权重。使用严格加载，不用strict=False隐藏不匹配，不修改磁盘权重。本版未新增工具函数。

### save_training_record(history, best_metrics, best_epoch, run_dir, best_model_config, training_model_config=None)

自写训练记录。向本次时间目录写training_history.csv和run_config.json，不写results。
记录超参数、已完成轮数、最佳配置、候选训练配置和selection_metric="validation_auroc"及tie_break_metric="validation_auprc"。两种配置可能不同，例如宽五层未超过旧窄五层模型。
best_epoch=0时不修改model/config.json；best_epoch>0时同步最佳模型说明。
每轮保存已完成记录，不保存完整终端文字、优化器状态或每轮权重副本。

### load_test_data(test_dir=TEST_DIR, test_csv=TEST_CSV)

自写清单读取。按test.csv顺序匹配JPG/JPEG/PNG，缺图时报错，返回无标签Dataset和名称列表。

### write_submission(image_names, positive_probability, output_csv=OUTPUT_CSV)

自写输出接口。检查数量与概率合法性，概率先保留6位小数，再按0.5生成标签，写UTF-8三列CSV并返回路径。不含绝对路径或DataFrame索引。

四个源文件合计19个函数/方法，没有额外训练框架。

## 8. 指标与记录字段

| 字段 | 含义 |
|---|---|
| train_loss / loss | 当前轮平均交叉熵，不含L2项 |
| train_accuracy / acc | 当前轮抽样训练样本的准确率 |
| accuracy / Acc | 有标签验证集准确率 |
| auroc | 阳性相对阴性的概率排序能力 |
| auprc | PR曲线梯形积分 |
| ap | 按召回增量加权的平均精度，与梯形积分不同 |
| recall / specificity | 阳性检出比例、阴性正确排除比例 |
| tp / tn / fp / fn | 真阳、真阴、假阳、假阴数量 |
| learning_rate | 该轮实际使用的学习率，epoch=0为空 |
| next_learning_rate | 调度后的学习率，早停后不会再使用 |
| best_epoch_this_run | 本次最佳轮，0代表仍保留运行前模型 |

阳性概率是softmax(logits)索引1。列固定为Image_name、Probability、Pred_Label，标签由写出的概率是否≥0.5计算。
5855行只证明清单完整，不代表预测正确；79分也不能换算成本地准确率。

## 9. 数据到位后如何运行与调整

数据已经位于glaucoma_first，不需移动原图。选择jitiaosai解释器，先运行submission/code/train.py，再按需要运行submission/code/predict.py，只上传results/submission.csv。
训练常量集中在utils.py；激活和失活默认参数在ImageModel.__init__，宽五层为固定结构。预测配置取自模型文件，不随训练默认值改变。尚未保存宽五层或未按AUROC优先、AUPRC决胜超过旧最佳时，predict仍使用磁盘上的原模型，这是正常保护机制。
修改图片尺寸或神经元数量会改变参数形状，不能只改一个常量。

回退79分基线时，停止程序，从基线目录复制模型和配置回submission/model，必要时恢复原CSV。先保留较新实验，避免覆盖。完整旧训练算法可从Git提交7597303恢复。
