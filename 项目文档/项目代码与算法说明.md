## 2. 工作流程

训练：读取官方train/valid → 验证磁盘旧冠军 → RESUME时迁移卷积/权重 → 每批前向、交叉熵、反向、截断、Adam更新 → 每轮验证 → 按AUROC保存候选最佳及正式冠军 → 调度/记录/早停。

预测：按pth内配置重建旧/新网络 → 按test.csv顺序读图 → eval/no_grad → Softmax阳性概率 → UTF-8三列CSV。

train调用predict.evaluate，不调用predict.predict。训练51396张、验证5849张、测试5855张；验证有标签，测试标签不公开。只使用图片，不使用Age字段。

## 3. 模型与原理

输入RGB64×64；固定卷积通道32→64→128→256→512。前三层3×3无padding，后两层3×3 padding=1。第1、2、5层卷积后做2×2最大池化；随后通道失活0.1，自适应平均池化到3×3。拉平4608维后经过512神经元、LeakyReLU、Dropout(0.5)，输出2个logits。

卷积用共享的局部加权求和提取特征；最大池化保留强响应，平均池化汇总局部信息；分类头综合这些特征。精简后3929410参数，FP32参数约15.72MB；减少参数不保证准确率提高，也不保证耗时等比例减少。

LeakyReLU负半轴保留0.01倍信号，保持已有特征计算；Dropout只在训练时随机失活，eval关闭。输出层不做Softmax，交叉熵接收logits，预测再转为概率。

使用普通交叉熵和Adam；L2权重衰减1e-4。已有卷积1e-5、新分类头1e-4；无旧权重或RESUME=False时全网1e-4。继续训练同一精简模型仍采用上述两组学习率，优化器状态不会恢复。

反向后、Adam更新前执行全参数L2梯度范数截断，上限5；若范数超过5则按比例缩小全部梯度。非有限梯度立即报错。它限制异常更新，不替代失活、验证或早停，也不是已证实的提分方法。

均衡采样按类别数量倒数给每张图权重，两类抽样概率约各半，每轮有放回抽取51396次；不是每张图片都恰好训练一次。不再额外加权交叉熵。训练保留随机水平翻转，验证/测试固定处理；缓存缩略RGB图，不改原图。

## 4. model.py中的函数

| 函数/方法 | 来源及作用 |
|---|---|
| create_dataset() | 复用课堂CNN todo1接口；调用load_train_data返回训练/验证Dataset |
| ImageModel.__init__(negative_slope=0.01, conv_dropout=0.1, dropout=0.5) | 复用课堂CNN搭建网络；本版将分类头精简为4608→512→2，结构标记wide5_slim |
| ImageModel.forward(x) | 复用课堂前向传播；固定五层卷积、池化、失活、拉平、分类，输入[N,3,64,64]输出[N,2] |

classifier中的Sequential仅把课堂全连接、激活、失活、输出按顺序组合。main只打印结构和参数，不读取训练图片或保存模型。

## 5. train.py中的函数

train(train_dataset, valid_dataset)：保留课堂DataLoader、model.train、前向、loss、zero_grad、backward、step循环；增加分组学习率、梯度保护、进度、验证及选模。

有旧权重时，即使RESUME=False也先验证它，防止较差候选覆盖；RESUME只决定是否迁移其权重。换分类头时迁移匹配卷积；同结构加载全部权重。默认起点是磁盘现有模型，不自动从Git恢复昨日模型。

每批64，首批/每25批/末批输出进度。每轮打印课堂epoch/loss/acc/time，然后调用evaluate打印验证指标。lr为卷积学习率，head_lr为分类头学习率。

**唯一保存条件：新验证AUROC严格提高。** 不使用ACC，不用AUPRC处理平局。公式为save = (没有旧模型) 或 (新AUROC > 旧AUROC)。AUPRC等仍显示，用于理解而非决定保存。

候选自身AUROC提高时保存到本次记录目录；超过正式冠军时另更新submission/model。两份pth都记录自身指标/轮数，不依赖一份可能不匹配的外部JSON。

学习率和早停比较候选自身进步；首轮建立基准，连续2轮未提高降为一半，最低1e-6；连续5轮未提高早停，最早第6轮，最多12轮。run_config.json中的validation/best_epoch_this_run描述正式冠军，不一定是本次候选最高值。

## 6. predict.py中的函数

| 函数 | 来源及作用 |
|---|---|
| evaluate(test_dataset, model=None) | 课堂CNN todo4验证循环；参数是有标签数据，eval/no_grad收集标签和Softmax[:,1]概率，打印并返回指标；不写提交CSV |
| predict(test_dir=TEST_DIR, output_csv=OUTPUT_CSV) | 课堂测试循环适配赛题；读取无标签test清单、正式权重并生成CSV，返回路径 |

predict模块被train导入不会执行main。已有权重按其自身结构加载；不训练新模型就运行predict，仍使用原权重，不会自动得到新模型成绩。

## 8. 记录与操作

训练记录字段learning_rate/head_learning_rate是本轮实际两组步长，next_learning_rate/next_head_learning_rate是调度后下一轮步长，epoch=0这些字段为空。selection_metric固定validation_auroc，tie_break_metric=null。训练目录pth包含自身validation、epoch、model_config。JSON顶层model_file/validation等属于正式冠军，candidate_best单独给出候选文件、轮数、指标和结构；两条路径均以project_root为基准，只有epoch=0时candidate_best为null。

train只生成权重及记录；predict才生成Image_name、Probability、Pred_Label。提交的是阳性概率，不是最大类别置信度。保存模型不自动重写旧CSV，用户训练后必须再运行predict。

用jitiaosai解释器运行；deepStudy不动。utils内调整训练参数，model内调整默认结构/失活；改输入尺寸要同步数据、配置及兼容检查，不能仅改常量。

官网仍按AUROC相等时AUPRC二次排序，本地依本次用户要求仅AUROC严格提高。原始数据不提交，不使用外部标注数据/预训练权重。旧模型保留在Git，可先备份再成对恢复模型/配置；本次不自动回滚。

## 9. 验证边界

轻量前向、合成反向（不做优化器step）、兼容/选模/保存测试不等于正式训练，更不代表官网成绩。已有模型/配置/CSV不变；新网络真实质量和正式环境≤100ms延迟都需后续验证。

参考：[PyTorch梯度截断](https://docs.pytorch.org/docs/2.10/generated/torch.nn.utils.clip_grad_norm_.html)、[官方规程](https://www.ncccu.org.cn/index/Paper/case2.html)。未经核实的高分宣传不作为参数选择依据。
