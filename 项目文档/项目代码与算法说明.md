# 青光眼分类项目：文件、函数与算法说明

版本：v1.5.2，日期：2026-10-17。方案A复用课堂CNN的四步接口、训练/验证循环及编号注释；网络改用torchvision的ResNet-18结构，所有参数从主办方训练数据学习，不使用外部预训练权重。

## 文件、数据和工作流程

| 文件或目录 | 用途 |
|---|---|
| submission/code/model.py | todo1读取数据接口、todo2网络定义；main打印网络结构和参数 |
| submission/code/train.py | todo3训练与验证；保存权重和本轮记录，不写提交CSV |
| submission/code/predict.py | todo4验证与无标签预测；main生成CSV |
| submission/code/utils.py | 数据适配、旧模型兼容、指标、学习率、权重及CSV工具 |
| submission/code/requirements.txt | 参考官方复现环境，无自动安装 |
| glaucoma_first/ | 官方train/valid/test及CSV，原图留本地 |
| submission/model/ | 全局正式冠军及配套说明 |
| submission/results/ | 仅放可以提交的submission.csv |
| 项目文档/训练记录/时间目录/ | 本轮曲线、候选最佳、训练前冠军备份 |

训练：先从官方train/valid读取有标签图片 → 检验并备份旧冠军 → 新建ResNet-18 → 均衡抽样、增强、前向、交叉熵、反向、梯度截断、AdamW更新 → 每轮固定验证集计算AUROC → 候选与全局冠军分别按AUROC保存 → 记录和早停。训练按钮不会写答案。

预测：读取pth中的网络结构、输入尺寸及预处理标记 → 按test.csv顺序读无标签图 → eval与no_grad → Softmax得到阳性概率 → 写UTF-8三列CSV。预测按钮不进行训练；测试无标签，因此不能显示真实准确率。

## 模型与算法

ResNet-18是CNN的一种。残差块将卷积得到的修正量与输入相加，方便更深的网络优化；它使用BatchNorm、ReLU与全局平均池化。此处输入RGB128×128，最后原1000类线性层改为Dropout(0.2)和二分类线性层；输出为两个logits。与普通CNN一样，卷积是局部共享权重的加权求和；交叉熵在内部处理logits的归一化，预测时再计算Softmax概率。

新网络约11177538参数，单精度裸参数约44.71 MB；实际pth需按落盘结果检查。旧模型维持自己的64像素输入和原结构。训练样本有放回均衡抽取，避免绝大多数批次看不到阳性；不额外叠加很大类别权重。验证集不参与梯度更新，也不与训练集混合计算选模指标。

方案A初始超参数：每批32，最大30轮；第1轮3e-5、第2轮3e-4，后续余弦衰减到1e-6；同结构续训峰值1e-5。至少跑10轮，候选自身AUROC连续8轮无改善后早停。交叉熵负责更新权重，独立验证AUROC严格超过全局冠军才更新正式模型；AUROC相等时不替换。梯度范数超过5缩小、出现NaN/Inf报错。训练增强仅有水平翻转、±15°旋转和亮度/对比度轻微变化；验证与测试固定处理。

## 各函数与方法

| 文件 | 函数/方法 | 来源及作用 |
|---|---|---|
| model.py | create_dataset | 复用day07 CNN todo1接口，调用工具读取主办方train/valid |
| model.py | ImageModel.__init__ | 沿用课堂模型初始化位置，调用torchvision ResNet-18(weights=None)，替换二分类头，登记结构/尺寸/预处理 |
| model.py | ImageModel.forward | 沿用课堂前向接口，执行残差网络并输出[N,2] logits |
| train.py | train | 复用课堂CNN todo3循环；增加旧冠军保护、增强、AdamW、预热/余弦学习率、验证AUROC选模及训练记录 |
| predict.py | evaluate | 复用课堂CNN todo4测试循环；按被测模型尺寸读取验证图，输出Acc/AUROC/AUPRC/AP/召回率等，不写CSV |
| predict.py | predict | 复用课堂预测循环，按正式权重尺寸读test清单并生成UTF-8提交答案 |
| utils.py | create_transform | 新写：共用RGB缩放/归一化，仅训练加温和随机增强 |
| utils.py | get_learning_rate | 新写：根据轮数给出两轮预热、余弦衰减后的学习率 |
| utils.py | ImageDataset.__init__ | 自写：保存路径、标签、输入尺寸、变换与图片缓存 |
| utils.py | ImageDataset.__len__ | 复用PyTorch Dataset标准接口，返回图片数 |
| utils.py | ImageDataset.__getitem__ | 自写：解码、缩放、缓存并生成张量和可选标签 |
| utils.py | _load_labeled_images | 自写：检查标注字段、0/1标签、图片存在性，兼容jpg/JPG |
| utils.py | load_train_data | 参考课堂数据接口：优先主办方独立valid；缺失时固定分层切分 |
| utils.py | create_sampler | 自写：按类别倒数生成均衡有放回抽样器 |
| utils.py | print_progress | 自写：首批/每25批/末批显示time与remaining |
| utils.py | calculate_metrics | 自写：由真实标签和阳性概率计算AUROC、AUPRC、AP等 |

| utils.py | LegacyImageModel.forward | 原课堂CNN的卷积、激活、池化、分类顺序，保证历史参数输出不变 |
| utils.py | load_model | 自写：读取pth结构、尺寸和预处理；恢复旧CNN或新ResNet，严格匹配参数 |
| utils.py | transfer_model_weights | 自写：仅相同网络和输入配置恢复参数；旧CNN不迁移到ResNet |
| utils.py | save_model | 复用课堂torch.save；原子替换pth，记录模型结构、尺寸、AUROC和轮次 |
| utils.py | save_training_record | 自写：记录本轮曲线、正式冠军和候选最佳，存项目文档目录 |
| utils.py | load_test_data | 自写：按官方test.csv顺序和模型尺寸构造无标签测试集 |
| utils.py | write_submission | 自写：写Image_name、Probability、Pred_Label三列，概率限于[0,1] |

## 有数据后的操作与调整

目前官方数据位于项目同级glaucoma_first，无需移动。使用jitiaosai运行train.py，观察每25批和每轮输出；训练完检查记录目录的candidate_best和正式模型是否更新。需要提交时单独运行predict.py，提交results/submission.csv。旧冠军是否被保留以验证AUROC决定，不看训练准确率。

下一步只在128像素实验完成之后再单独评估160像素；须连同权重配置、测速与验证一起调整，不能直接把旧pth当作新尺寸权重。模型成绩需要独立验证和官网评分，代码可运行不等于保证达到98分。
