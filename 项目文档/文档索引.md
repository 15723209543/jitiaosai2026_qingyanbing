# 项目文档索引

- `当前状态/`：最终交接、使用说明与训练结果。
- `训练计划/`：按日期归档的历史训练方案。
- `训练记录/`：各轮真实日志、验证和候选记录。
- `提交记录/`：比赛提交与打包记录。
- `历史研究记录/`：报告、旧版状态及配方。
- `数据分析/`、`评价指标说明/`、`数据格式示例/`：数据与指标资料。
- `修改说明/`：历史代码与目录调整说明。
- `交付材料/`：按指定模板生成的 README/LICENSE 完成版文件夹与 ZIP。

比赛终版为仓库根目录 `submission/`；其官网成绩由用户截图提供。原始数据、训练断点和本机归档不随 Git 仓库发布。
