# 以98.10分参考为基准的三档判定

本文件夹对 **5,855** 张测试图片逐张应用用户指定的规则。`本人前9次报阳次数`只统计本人第1—9次归档 CSV 的 `Pred_Label`；第10、11次属于数据分析产生的提交，**不计入投票，也不参与规则判定**。`98.10参考Pred_Label`来自用户提供的[第8次提交对比.xlsx](../../提交记录/第8次提交对比.xlsx)第二组标签。

## 判定顺序

1. **确认**：本人前9次全报0且参考报0，显示“确认阴性”；前9次全报1且参考报1，显示“确认阳性”。这一档优先于后两档。
2. **大概率**：参考报1且本人前9次报阳次数 **大于5**，显示“大概率阳性”；参考报0且报阳次数 **小于5**，显示“大概率阴性”。
3. **判断**：剩余图片中，参考报1时，本人仅报阳 **0、1、2次** 则显示“判断为阴性”，其他次数显示“判断为阳性”；参考报0时，本人报阳 **8、9次** 则显示“判断为阳性”，其他次数显示“判断为阴性”。恰好报阳 **5次** 的图片进入这一档。

各档最终标签分别是阴性 `0`、阳性 `1`。这些词是**规则输出的显示名称**：“确认”只表示指定预测完全一致，**不表示有医生诊断或真实测试标签**；“大概率”也不是经过概率校准的患病概率。

## 结果

| 显示结果 | 图片数 |
| --- | ---: |
| 确认阴性 | 4,390 |
| 确认阳性 | 125 |
| 大概率阴性 | 799 |
| 大概率阳性 | 99 |
| 判断为阴性 | 292 |
| 判断为阳性 | 150 |
| **合计** | **5,855** |

按本规则最终报阳 **374** 张、报阴 **5,481** 张。这个数量由人工规则产生，**不是新的官网成绩，也不能推断该方案比第11次的94.89分更高**。

- [逐图判定.csv](逐图判定.csv)：保留第1—9次逐次标签、报阳次数、参考标签、档位、显示结果、最终标签和命中的判定基准，按 `test_00000.jpg` 至 `test_05854.jpg` 的原顺序排列。
- [分组统计.csv](分组统计.csv)：按本人前9次报阳次数（0—9）与参考标签（0/1）列出20组的六类结果，便于核对边界。
- [submission.csv](submission.csv)：可按比赛要求上传的三列文件，列名依次为 `Image_name,Probability,Pred_Label`，共5,855行；其中374行标签为1。

`submission.csv` 的 `Pred_Label` 取自上述规则。`Probability` 原则上沿用98.10分参考文件的对应值；在196张参考标签与规则标签不一致的图片中，为保证概率与0.5阈值下的标签一致，将其中87张需要报阳的概率调整为 `0.5000000000`，109张需要报阴的概率调整为 `0.4999990000`。这些数值只是提交格式所需的启发式分数，**不是经过校准的患病概率，也不能据此保证官网得分**。

所有输入按 `Image_name` 对齐，检查了每份输入的5,855个唯一图片名、二元标签、输出分组总数、提交顺序以及 `Pred_Label = (Probability ≥ 0.5)`。没有修改此前提交记录、模型或 `submission/results/submission.csv`。
