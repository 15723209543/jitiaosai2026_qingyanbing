更新日期：2026-10-15。助手只修改代码和轻量检查，不执行正式训练或整批预测。

本次改动前，先将工作区最新的三层模型及10轮记录提交为 `0080485 / v1.2.1` 并推送，代码修改不覆盖现有权重或CSV。

最新记录位于 `训练记录/20261015_082205_596074/`：第5轮最佳AUROC为0.896694、梯形AUPRC为0.418619、AP为0.420473、召回率为65.45%；第10轮训练acc达到95.75%，验证AUROC仍未超过第5轮。

与本轮起始AUROC 0.896657相比提升很小，说明继续按原设置训练的收益有限；这不是“层数不足”的证明。此次按用户确认方案增加两层卷积，作为待验证实验，不预先承诺提分。

## 2. 已实施、由用户运行的方案

- 卷积从3层增加到5层，通道32→64→128→128→128。新增两层3×3、padding=1，插在第三次池化前。
- 保持64×64输入、三次池化和两个2048神经元全连接层，原有层继承权重；新增卷积使用Dirac/零偏置初始化，参数可训练。
- 保留LeakyReLU(0.01)、卷积Dropout2d(0.1)、全连接Dropout(0.5)；验证和预测关闭失活。
- 保留Adam，初始学习率5e-5，L2权重衰减1e-4。
- 验证AUROC连续2轮没有超过调度器记录值至少1e-4时，学习率减半，最低1e-6。
- 最多12轮，连续5轮未超过最佳模型提前停止。最佳模型优先AUROC，相同时比较梯形AUPRC。
- 保留均衡采样、普通交叉熵、训练水平翻转和内存缓存，不新增外部数据或复杂框架。

本轮主要改变卷积深度，学习率、轮数、失活和数据处理保持不变。新增卷积本身初始化为原样传递特征，但额外LeakyReLU仍会改变负值；不能认为五层模型一开始就完全等于三层模型。

## 4. 训练记录

每次运行创建精确到微秒的独立时间目录：

- training_history.csv：epoch、loss/acc、验证指标、该轮及下一轮学习率。
- run_config.json：超参数、实际完成轮数、最佳轮次、最佳模型配置和候选训练配置。

epoch=0是旧配置的基准验证，没有训练loss/acc。best_epoch_this_run=0时，原pth和model/config.json不变，但本次记录仍保存。model_config是实际保存的最佳模型配置，training_model_config是本次候选配置；extra_convs=0代表三层，2代表五层。二者不同表示新模型尚未超过旧最佳。
每轮及时记录已完成结果，不自动保存完整终端文字、优化器状态或每轮权重副本。

## 5. 后续实验一次改一个因素

| 顺序 | 因素 | 对比方法与风险 |
|---|---|---|
| A | 五层与三层 | 从相同三层基线开始对比；只读检查不能当作新模型成绩 |
| B | 激活函数 | 同一起始权重下比较negative_slope为0与0.01 |
| C | 卷积失活 | 比较conv_dropout为0、0.05、0.1，避免过强导致欠拟合 |
| D | 学习率 | 比较3e-5与5e-5，同时记录衰减次数 |
| E | 提高图片分辨率 | 本版不做；需同步全连接输入或池化，另行确认 |
| F | 增加卷积通道 | 本版不做；参数形状改变，需要重考虑权重迁移 |

五层总参数14028098个，增加295168个，大部分参数仍在全连接层。本次不加宽全连接层，不继续盲目叠更多层。若验证仍停滞，先比较三层与五层记录再决定下一步。只能使用主办方数据，不加入外部标注数据，不用无标签测试集代替验证集。

## 6. 回退方法

回退79分版本：程序停止时，把基线目录中的best_model.pth、config.json复制回submission/model，必要时恢复基线CSV。回退本次最新三层版本：从Git提交0080485恢复model下的参数和配置；操作前先保存后来实验，不直接强制重置整个项目。
新代码兼容旧纯权重及v1.2.x配置，预测自动恢复对应三层结构。想继续训练三层对照，还需把ImageModel默认extra_convs设为0；已有五层权重不能直接迁入三层。
完整旧训练算法在Git提交7597303中；只恢复权重不会把下一次训练默认设置改回旧版。
