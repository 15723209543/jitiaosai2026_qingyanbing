# 当前使用说明（2026-10-31，V1.20.4）

根目录保留两份原始数据、`submission`、`submission2`、`submission3`、`项目文档`、两份比赛 PDF 与 README。原始数据和 junction 目标只读。

## 提交文件

初赛仅上传各路线 UTF-8 的 `submission.csv`，表头 `Image_name,Probability,Pred_Label`，5855 行，按官方 test 顺序。当前最佳两份候选位于 `submission2/submission.csv` 和 `submission3/submission.csv`，均已核验并可分别上传；今天这两份最终文件的官网分数尚未知。正式 `submission/` 未改动。详情见 [训练结果](训练结果.md)。

## 路线与选模

- `submission/`：正式双骨干模型，官方独立 valid AUROC 0.9859689935392411。
- `submission2/`：官方 train 全量、focal + margin AUC、BF16；当前最佳为 10 月 31 日晚间 LR 5e-6 第 1 轮，valid AUROC 0.9859523373289731。见 [配方](submission2_RECIPE.md)。
- `submission3/`：统一双骨干联合训练器，`--mode holdout --percent 80` 为 80/20 内部诊断，`--mode independent --percent 80` 为独立 80/80。当前最佳为后者 LR 5e-6 第 1 轮，valid AUROC 0.9859541880190029；后续 LR 3e-6、4e-6 试验未超过。见 [配方](submission3_RECIPE.md)。

官方 valid 不参与训练，只用于 AUROC 选模；内部抽样指标不能替代它。正式权重只有严格超过正式基线才晋升。`runs/` 仅本机保留，变参数不得跨 run `--resume`。模型推理与计时共用实现；官方 test 不用于调参。

## 跨电脑复现最终两份 CSV

克隆后先运行 `git lfs pull`，再从项目根目录执行：

```powershell
python submission2/code/predict.py submission2/submission.csv --checkpoint "项目文档/训练记录/20261031_晚间追加训练/submission2/candidate_epoch1.pth"
python submission3/code/predict.py submission3/submission.csv --checkpoint "项目文档/训练记录/20261031_候选权重/submission3/candidate_epoch1.pth"
```

10 月 30 日旧 CSV 平台成绩分别为 97.87、97.81（用户提供），不能当作今天文件成绩。旧模型与迁移备份 ZIP 保存在 Git 忽略的 `项目文档/归档_本地/`；旧 submission2/3 另有 GitHub Release。
