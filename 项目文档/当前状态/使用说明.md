# 使用说明：最终 98.05 提交包

本目录状态截至 2026-11-07。比赛已结束。`submission/` 是最终提交包的 15 个文件，`submission/submission.csv` 已生成，上传或审阅无需重复推理。模型与 CSV 的哈希见 [AI 交接](AI_HANDOFF.md)。

安装依赖：在 `submission/` 目录执行 `python -m pip install -r code/requirements.txt`。正式推理入口为 `code/predict.py`，可运行 `python code/predict.py --help` 查看 `--mode`、两权重和输出参数；其 `test` 模式需要主办方原始图像目录与有效的 `model/ensemble_valid.json`。测试图像不在仓库。`python cost.py <100张图像目录> <5张图像目录>` 使用同一预测实现做计时与一致性核对。

当前 CSV 有 5,855 行，列为 `Image_name,Probability,Pred_Label`，官方顺序与 0.5 标签阈值已核验。若在另一台机器运行，先 `git lfs pull` 拉取模型；需配置 CUDA、PyTorch 及 `code/requirements.txt` 中的依赖。比赛指定硬件的延迟应另行复测。本机记录与校验限制见 [训练结果](训练结果.md)。

根目录三份 PDF 是官方比赛材料，原始图像和本机训练断点不随仓库分发。历史训练记录、提交记录与研究方案分别在 `项目文档/训练记录/`、`项目文档/提交记录/`、`项目文档/历史研究记录/`。
