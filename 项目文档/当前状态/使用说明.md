# 当前使用说明（2026-10-31）

根目录保留两份原始数据、`submission`、`submission2`、`submission3`、`项目文档`、两份比赛 PDF 与 README。原始数据和 junction 目标只读。

## 提交文件

初赛仅上传各路线 UTF-8 的 `submission.csv`，表头 `Image_name,Probability,Pred_Label`，5855 行，按官方 test 顺序。今日 `submission2/submission.csv` 与 `submission3/submission.csv` 均已核验，可分别上传；它们是不同的候选预测，今日官网成绩尚未知。正式 `submission/` 未改动。详情见 [训练结果](训练结果.md)。

## 路线与选模

- `submission/`：正式双骨干模型，官方独立 valid AUROC 0.9859689935392411。
- `submission2/`：官方 train 全量，focal + margin AUC；今天 BF16、LR 1e-5 两轮，第 1 轮最佳，未晋升。见 [submission2 配方](submission2_RECIPE.md)。
- `submission3/`：统一双骨干联合训练器。`--mode holdout --percent 80` 是 80/20 内部诊断；`--mode independent --percent 80` 是独立 80/80。今天采用后者，以 BF16、LR 5e-6 训练两轮，第 1 轮最佳，未晋升。见 [submission3 配方](submission3_RECIPE.md)。

`--percent` 可输入 1–99。官方 valid 不参与训练，只用于 AUROC 选模；内部抽样指标不能替代它。正式权重仅在官方 valid AUROC 严格超过基线时晋升。旧 run 不可跨参数 `--resume`。`runs/` 不推送；今日候选权重由 Git LFS 保存。

## 跨电脑复现今日 CSV

先运行 `git lfs pull`，再从项目根目录执行：

```powershell
python submission2/code/predict.py submission2/submission.csv --checkpoint "项目文档/训练记录/20261031_候选权重/submission2/candidate_epoch1.pth"
python submission3/code/predict.py submission3/submission.csv --checkpoint "项目文档/训练记录/20261031_候选权重/submission3/candidate_epoch1.pth"
```

`code/predict.py` 与 `cost.py` 共用推理实现。官方 test 只用于预测，不用于调参。10 月 30 日旧 CSV 平台成绩分别为 97.87、97.81（用户提供），不能当作今日成绩。旧版快照见 [多轮训练](../训练记录/20261031_多轮训练/README.md)。旧模型与迁移备份 ZIP 在 Git 忽略的 `项目文档/归档_本地/`，旧 submission2/3 另有 GitHub Release。
