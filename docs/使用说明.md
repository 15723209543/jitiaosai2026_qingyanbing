# 使用说明（2026-10-26）

设备选择：点击 `submission/code/train.py` 运行时会先打印当前使用 GPU 还是 CPU、PyTorch 与 CUDA 版本。有 CUDA 则优先 GPU；无 CUDA 也可用 CPU，训练逻辑相同但可能非常慢。当前本地 `deepStudy` 为 CPU 版。工作树中两个模型的 `CONFIG[...]["epochs"]` 暂设为 1，而已有权重记录的最佳轮次分别是 6 和 3；若要继续训练，请先将各目标轮次设为高于对应已完成轮次。设备修复没有启动完整训练，也没有改动 PTH 或 CSV。

当前唯一代码目录是 `submission/`，由原 `submission2/` 改名；`glaucoma_first/` 数据目录与之同级。旧 ResNet-18 + DenseNet-121 方案已从当前工作树移除，可从 Git 历史恢复。根层 `submission/submission.csv` 仍是旧方案的 5,855 行历史提交结果，与 `Downloads/submission (4).csv` 字节一致，**不是现用预训练双模型的预测输出**。

现用方案位于 `submission/`：在 GPU 主机先安装适配 CUDA 的 PyTorch，再安装 `submission/code/requirements.txt`，运行 `python submission/code/train.py`。只使用主办方 `glaucoma_first/train` 更新参数、`valid` 选 AUROC。本机已从 Git LFS 取回约 200.8 MB 的真实阶段性 `best_model.pth` 并安全读取：ConvNeXt-Tiny 最佳第 6 轮（记录 AUROC 0.984011），EfficientNetV2-S 最佳第 3 轮（记录 AUROC 0.965275）；检查点的 `training_complete=False`、`selection=None`，**不能直接预测**。训练机若仅拉到约 134 字节的 LFS 指针，须先运行 `git lfs pull` 取得真实权重。重新运行 `train.py` 会先用完整官方验证集复核已有参数，再从各自最佳轮次之后继续；旧 PTH 不含优化器状态，故不是精确批次续训。训练与验证每 25 批打印本批阳性、报阳、报对、误报和漏报。训练完整结束并选好方案后，单独运行 `python submission/code/predict.py` 才写该模型的 CSV。`cost.py` 与 `predict.py` 共用推理函数。0.99 只是检验目标，不能报告为成绩。

目录职责和新规程材料清单见 `目录整理与报错核查_20261026.md`；历史训练记录见 `训练结果.md`。最终网站提交由用户执行，当前没有制作 ZIP；打包前必须完成训练与选模、生成与该模型匹配的新 CSV，并补齐预训练来源、许可证、核验表和真实权重文件。

仓库清理后的旧实验、旧轮权重和历史快照在本地 `历史归档_本地/旧实验与过期提交材料_20261026.zip`，只作恢复备份，不属于最终提交材料；见 `仓库清理记录_20261026.md`。本次替换前的正式模型/源码亦可由 Git 历史恢复。
