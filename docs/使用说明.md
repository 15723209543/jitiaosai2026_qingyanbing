# 使用说明（2026-10-26）

当前正式提交目录是 `submission/`，根层 `submission.csv` 是最近提供的 5,855 张测试图预测，与 `Downloads/submission (4).csv` 完全相同。正式模型的已记录官方验证 AUROC 为 0.964011，模型/CSV 都没有被本轮代码覆盖。当前本机正式 PTH 仅为 133 字节 Git LFS 指针，不能直接运行；训练机须拉取完整 LFS 对象并验证 SHA-256，不能把指针作为最终材料。

新候选位于 `submission2/`：在 GPU 主机先安装适配 CUDA 的 PyTorch，再安装 `submission2/code/requirements.txt`，运行 `python submission2/code/train.py`。只使用主办方 `glaucoma_first/train` 更新参数、`valid` 选 AUROC。训练完成才生成 `submission2/model/best_model.pth`；想生成候选 CSV 时单独运行 `python submission2/code/predict.py`。`cost.py` 用与 `predict.py` 相同的推理函数。新候选尚未训练，0.99 只是检验目标，不能报告为成绩。

原正式目录的文件职责和新规程材料清单见各自 README；两次训练记录见 `训练结果.md`。最终网站提交由用户执行，当前没有制作 ZIP；打包前必须补齐预训练来源、许可证和真实权重文件。
