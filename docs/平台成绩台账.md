## 3. 判读规则（重要，避免以后误判）

1. **平台分数是 CSV 的确定性函数**：隐藏测试集固定、指标固定，同一个 CSV 就是同一个分。因此版本之间的分差**是真实的模型差异，不是运行噪声**。
2. **但"我们挑哪个模型"依赖的官方 valid 只有 191 个阳性**。按 Hanley–McNeil 近似，valid AUROC 的 1 个标准误约 **0.006**（95% 区间约 ±0.012）。也就是说：
   - v1.16.4 号称的 +0.00135 只有约 0.2 个标准误，**与噪声无法区分**；
   - 凡是 valid 上小于 0.005 的"提升"，都不能作为晋升依据。
3. **不得用测试集分数调参**：不得按平台分数挑阈值、挑轮次、拟合融合权重。跨版本对比平台分数只用于判断"方向对不对"，不能用测试集反选模型（项目规则已明确禁止）。
4. 判断"方向"时的正确读法：**先看平台分数，再看 valid**。v1.16.4 正是"valid 涨、平台掉"的典型，说明 valid 已被前面的选模消耗掉了独立性。
