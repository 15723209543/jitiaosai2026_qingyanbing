# jitiaosai2026_qingyanbing / 2026年第八届全国高校计算机能力挑战赛大数据赛道——青眼病题
一个基于 **Python、Windows 与 Python 3 环境和PyTorch、timm** 开发的算法项目。项目主要实现青光眼眼底图像二分类与概率预测，并支持ConvNeXt-Small 和 ConvNeXt-Tiny 融合推理、官方测试集 CSV 导出、模型计时与一致性核验等功能，适合作为比赛项目。
> **特别说明：**比赛已结束；官网最终成绩 98.05，未获奖。本地官方 valid AUROC 为 0.9883804426480413，两个数值来自不同数据集。

## 2. 项目简介
本项目是2026年第八届全国高校计算机能力挑战赛大数据赛道“青眼病题”的团队最终成果归档，不是面向临床的诊断软件。`submission/` 包含官网最终 98.05 分对应的模型、推理代码、CSV、计时入口和数据申明清单；`项目文档/` 保存研究与训练记录。仓库地址为 https://github.com/15723209543/jitiaosai2026_qingyanbing 。预测输出分类标签与阳性概率。
### 2.1 本次版本重点
本版归整最终提交目录，保留官方比赛 PDF 与项目文档，并新增统一的 README 和 LICENSE。模型权重与 CSV 沿用 2026-11-06 官网得分 98.05 的最终提交，不重新计算预测。

## 3. 已实现功能
### 3.1 基础功能
使用 `submission/code/predict.py` 加载 Small 与 Tiny 权重，对图像批量推理并生成 `submission.csv`；`submission/cost.py` 对 100 张样本计时并核对提交概率。
### 3.2 核心规则或业务功能
两模型分别输出阳性概率，按固定 0.5/0.5 权重融合，再按 0.5 阈值得到预测标签；官方 valid 用于 AUROC 选模，测试集仅用于最终推理。
### 3.3 自动化测试
`submission/cost.py` 提供与正式预测相同的推理实现与 100 张图像一致性检查；历史实验与本地验证记录保存在 `项目文档/`。
---
## 4. 运行环境
Python 3、CUDA 兼容 GPU、PyTorch、torchvision、timm、safetensors、NumPy、Pillow、scikit-learn；版本范围见 `submission/code/requirements.txt`。运行需要主办方提供的图像目录，原始数据不在仓库。
---
## 5. 运行方法
### 5.1 使用命令行运行
在 `submission/` 目录执行 `python -m pip install -r code/requirements.txt`；运行 `python code/predict.py --help` 查看输入目录和权重参数，再按主办方数据路径调用。计时命令为 `python cost.py <100张图像目录> <5张图像目录>`。

## 7. 主要算法与实现思路
### 7.1 程序主流程
输入图像经相同的 320 像素预处理后分别送入两个 ConvNeXt 模型，融合阳性概率，输出按官方顺序排列的 CSV；`cost.py` 复用同一预测实现。
### 7.2 双模型概率融合
解决单模型误差互补问题：输入同一眼底图像，分别计算 Small 和 Tiny 阳性概率，按预先固定的 0.5/0.5 系数求均值，输出概率和阈值标签。
