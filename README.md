# 2026 青光眼眼底图像二分类

当前版本：**v1.4.1**。沿用课堂CNN四步，固定五层卷积，本地训练与预测，初赛只提交submission.csv。

## 1. 本版修改

- 本次model.py不变，沿用固定五层卷积：32→64→128→256→512。
- 保留三次最大池化，和一次自适应平均池化，把512×6×6汇总为512×3×3。
- 全连接仍为4608→2048→2048→2。总参数15208258个，float32参数约60.83MB，模型文件低于500MB；训练内存和耗时不等同于文件大小。
- train.py保留两段可注释切换的选模代码，**当前启用方案2（验证ACC）**：准确率严格提高才保存，相等不保存。方案1（AUROC优先、相同看AUPRC）保持注释。
- 学习率和早停观察本次候选模型自身的所选验证指标（ACC或AUROC），不以旧冠军为进步门槛。首轮建立自身基准；随后连续2轮未超过自身最高值则学习率减半，连续10轮未提高则早停。其他指标继续打印。

官网主要指标仍是AUROC，并未因本地修改而改变。验证集5658/5849张为阴性，全预测阴性也可达到96.73%准确率，因此准确率上升不保证比赛分数上升。

切换方法：在train.py中找到“方案1/方案2”，给不使用的整段加三引号，删除要使用那段前后的三引号。**始终只启用一段，不要两段都打开或都注释。** 不需要改其他文件，模型配置和记录会按实际方案标注。训练acc不参与选模。

- results只放提交答案，全部程序源码只在submission/code的四个Python文件内。

## 4. 旧权重与续训

旧三层、旧窄五层均由utils按原结构加载，预测结果不因新结构改变。新结构配置标记为architecture=wide5，没有层数开关。

从旧模型开始时先验证它，再仅迁移前三个卷积层。后两层变宽，池化后特征组织也变了，所以后两层和分类头使用PyTorch默认初始化；不使用旧Dirac初始化。宽五层继续训练时恢复全部权重。RESUME只恢复权重，优化器/调度器重新初始化。

只有按当前启用方案的指标超过磁盘旧模型才覆盖它；否则仍保留旧模型。本次助手未覆盖模型、配置或答案，保留用户刚生成的文件。

用户记录20261015_153819_312440中，宽五层第4轮AUROC=0.918078、AUPRC=0.436519，高于原模型0.898348和0.417890；但Acc=91.84%低于原模型92.51%，被上一版准确率规则排除。已有改善迹象，先修正选模规则，不继续加层。未保存的第4轮权重无法从CSV恢复，需由用户重新训练。

## 5. 后续调整

utils.py：学习率5e-5、weight_decay=1e-4、最多12轮、候选模型自身所选验证指标连续10轮未提高则早停；连续2轮未提高则学习率减半，最低1e-6。batch64、CPU线程8。
model.py：LeakyReLU斜率0.01、卷积Dropout2d(0.1)、全连接Dropout(0.5)。本次没有增加层数选择参数。
