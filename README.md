## 2. 项目简介


**项目背景与目标：**本项目源于 **2026年第八届全国高校计算机能力挑战赛大数据赛道** 的“青眼病题”，是团队针对赛题要求持续完成算法研发与竞赛提交的**最终成果**。我们的任务不是开发一套面向临床的医疗系统，而是按照主办方给定的眼底图像分类任务和提交规范，构建可复现的训练、验证与预测流程，输出符合官方格式的分类概率与标签，并完成竞赛要求的模型、代码及核验材料交付。

**最终交付：** `submission/` 汇集训练与预测代码、ConvNeXt 双模型权重、最终提交的 `submission.csv`、运行计时脚本、模型核验材料和来源许可说明；`项目文档/` 记录赛题研究、实验迭代与方案调整。相关比赛规程也保留在仓库根目录，以便了解赛题背景与提交约束。仓库地址：https://github.com/15723209543/jitiaosai2026_qingyanbing。仓库原有记录记载最终官网成绩为 **98.05**、未获奖；该成绩为历史竞赛记录，本次文档整理未重新评测。

## 3. 已实现功能


### 3.1 基础功能


submission/code/train.py 提供 Small/Tiny 模型训练代码；submission/code/predict.py 加载双模型权重，运行官方验证集指标计算、测试集批量预测及 CSV 输出；submission/cost.py 提供 100 张图像计时与结果一致性核验入口。

### 3.2 核心规则或业务功能


通过 utils.py 读取官方 train、valid、test 划分及 CSV，验证文件存在性和标签；对眼底图片等比缩放并补边为 320×320；Small 与 Tiny 分别计算阳性概率并按 0.5/0.5 融合，以 0.5 阈值生成 Pred_Label。CSV 列为 Image_name、Probability、Pred_Label。

### 3.3 自动化测试


submission/cost.py 使用与正式预测相同的推理入口执行计时、100 张图像的概率对照及一致性核验；此次仅静态审阅代码，未实际执行。

## 4. 运行环境


Python 3；torch>=2.3,<3、torchvision>=0.18,<1、timm>=1.0,<2、safetensors>=0.4,<1、numpy>=1.26,<3、Pillow>=10,<12、scikit-learn>=1.4,<2。训练代码要求 CUDA GPU，预测代码允许 CPU 回退。需另行提供竞赛官方图片和 train/valid/test.csv；仓库模型为 Git LFS 管理。

## 5. 运行方法


### 5.1 使用命令行运行


在仓库根目录安装依赖：`python -m pip install -r submission/code/requirements.txt`。下载 LFS 权重：`git lfs pull`。在 submission/ 目录查看预测参数：`python code/predict.py --help`。计时命令：`python cost.py <100张图片目录> <5张图片目录>`。运行前使用 `GLAUCOMA_DATA_ROOT` 指向含官方分组 CSV 与图片的目录。

## 7. 主要算法与实现思路


### 7.1 程序主流程


按官方 CSV 顺序读取图片 → 320×320 等比缩放补边及归一化 → Small/Tiny 分别前向推理 → 0.5/0.5 概率融合 → 0.5 阈值分类 → 导出官方格式 CSV；验证模式另输出 AUROC、AP 与混淆计数。

### 7.2 双模型概率融合


同一眼底图像经两个 ConvNeXt 分类网络分别输出阳性概率，计算两者均值作为最终概率，并据此生成二分类标签，减少依赖单一模型的预测结果；模型使用独立权重文件。
